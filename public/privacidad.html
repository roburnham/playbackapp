Política de Privacidad de Playback

Última actualización: 3 de julio de 2026

Playback ofrece una aplicación web y una extensión de navegador ("Playback Subtitles") que permiten a un grupo de personas ver contenido audiovisual de forma sincronizada, compartiendo comentarios que aparecen en el momento exacto de la reproducción.

1. Responsable

Playback es un proyecto personal. Para cualquier consulta sobre esta política o tus datos, puedes escribir a rocioburon@gmail.com.

2. Qué datos recogemos

Al usar una sala de Playback (desde la web o desde la extensión de Chrome) se recogen:

  • El nombre o apodo que escribes al entrar en una sala.
  • El texto de los comentarios que escribes.
  • El código de la sala y el minuto del vídeo al que corresponde cada comentario.

No recogemos contraseñas, datos de pago, ubicación, historial de navegación ni ningún dato de identificación oficial. No usamos cookies de seguimiento ni analítica de terceros.

3. Cómo se usan estos datos

Estos datos se usan únicamente para mostrar los comentarios a las demás personas conectadas a la misma sala, en el momento correcto de la reproducción, y para gestionar el temporizador compartido. No se usan con fines publicitarios ni se elaboran perfiles de usuario.

4. Con quién se comparten

Los comentarios y el nombre asociado son visibles para cualquier persona que entre en la misma sala usando el código correspondiente. Los datos se almacenan en Supabase (proveedor de base de datos en la nube) como encargado del tratamiento. No vendemos ni cedemos tus datos a terceros con fines comerciales.

5. Extensión de Chrome "Playback Subtitles"

La extensión usa los mismos datos que la app web (nombre, comentarios, código de sala) y se comunica con la misma base de datos de Supabase para mostrarlos como subtítulos sobre el vídeo que estés viendo. La extensión también guarda localmente en tu navegador (chrome.storage) tu sesión (sala, nombre, parte actual, tamaño de subtítulo) para recordar tu conexión entre usos.

6. Conservación y eliminación

Los datos de una sala permanecen almacenados mientras no se solicite su eliminación. Si quieres que borremos tu nombre o tus comentarios, escríbenos a rocioburon@gmail.com indicando el código de sala.

7. Cambios en esta política

Podemos actualizar esta política si cambian las funcionalidades de la app o la extensión. La fecha de la última actualización aparece al principio de esta página.
